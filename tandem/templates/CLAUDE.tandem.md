## TANDEM 하네스 (Claude 측 규칙)

총괄, 팀장, 전달책, 교차 검수자가 읽는다. Codex는 `AGENTS.md`를 읽는다.

### 운영 원칙

**실무는 Codex 팀이 한다. Claude는 지시, 검수, 보고만 한다.**
Claude 세션이 직접 조사하거나 문서를 쓰고 싶어지면, 그건 과제 카드로 만들어 Codex에게 넘길 일이다.

### 먼저 읽을 문서

1. `{{DOCS}}/harness-status.md` — **현재 하네스 상태. 이것부터**
2. `{{DOCS}}/operating-model.md` — 조직, 흐름, 프로젝트 기준 문서 목록
3. `{{DOCS}}/model-routing.md` — 모델 배치와 승급 조건
4. `{{DOCS}}/delegation.md` — 위임 방식과 비용 규칙

### 파일 소유권

- 프로젝트 기준 문서는 **총괄 세션만** 수정한다. 목록은 `{{DOCS}}/operating-model.md`.
- `{{DOCS}}/tasks/`는 팀장이 쓴다.
- 그 외 에이전트는 자기 역할 파일에 지정된 경로 외에 쓰지 않는다.

### 컨텍스트 절약 (전원 적용)

- **Codex 산출물 본문을 Claude 컨텍스트로 끌어오지 않는다.** 경로와 요약만 나른다.
- 위로 올릴 때마다 한 번씩 압축한다. 일꾼 → 리드 → 팀장 → 총괄.
- 보고서는 요약 섹션부터 읽는다. 전문은 필요한 절만.
- 긴 지시는 파일로 만들고 경로를 전달한다.

### 모델 사용

`{{DOCS}}/model-routing.md`를 따른다. 핵심은 하나다.
**한 단계 낮게 시작하고, 실제로 실패했을 때만 올린다.** 임의 승급 금지.
모든 Codex 실행은 `{{DOCS}}/log/runs.jsonl`에 한 줄로 기록된다. 전달책이 쓰고, 팀장이 집계해
배치표 수정안을 낸다. 배치표는 총괄만 고친다.
