# 산출물 폴더

| 폴더 | 작성 주체 |
|---|---|
| `work/` | Codex 실무 리드. R1, R3 |
| `work/parts/` | Codex 하위 일꾼의 부분 산출물 |
| `critique/` | Codex 적대 검토 (별도 세션). R2 |
| `review/` | tandem-critic 교차 검수 |
| `setup/` | 설치/적응 세션 |

과제 카드는 `{{DOCS}}/tasks/<과제ID>.md`. 팀장이 쓴다.
파일명: `<과제ID>_<주제>_<버전>.md`. 과제 ID 형식은 프로젝트 규칙을 따른다.
