# 실패 교훈

교훈은 {{DOCS}}/lessons/lessons.md에 기록한다. 첫 기록 때 만들며 설치 대상은 아니다. 세션 시작에 자동으로 읽지 않는다.
한 줄 형식: `- YYYY-MM-DD [태그,태그] 증상 -> 원인 -> 다음엔 이렇게 (xN)`. `(xN)` 은 같은 교훈이 쓰인 횟수다. 처음에는 생략한다(= x1).
하위 결과 요약 첫 줄이 `STOPPED:`이거나 승급·재시도 끝에 실패를 해결하면 카드 작성자가 기록한다. 같은 교훈이 있으면 새 줄 대신 기존 줄의 날짜를 갱신하고 `(xN)` 을 1 올린다. 카드에 붙인 교훈이 실제로 실패를 막았을 때도 1 올린다.
카드 쓰기 전 `tandem/tools/lessons.ps1 -Tags <태그,태그>` 를 실행한다. 횟수 많은 순, 최근 순으로 최대 3줄(`-Top`)이 나온다. 그 줄만 카드의 "배경"에 붙인다. 파일 전체를 읽지 않는다.
`(x3)` 이상인 교훈은 기준 문서(operating-model 등)로 올리고 해당 줄을 지운다. 40줄을 넘으면 횟수가 x1 이고 90일 지난 줄부터 지운다.
