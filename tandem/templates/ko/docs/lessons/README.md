# 실패 교훈

교훈은 {{DOCS}}/lessons/lessons.md에 기록한다. 첫 기록 때 만들며 설치 대상은 아니다.
한 줄 형식: `- YYYY-MM-DD [태그,태그] 증상 -> 원인 -> 다음엔 이렇게`
하위 결과 요약 첫 줄이 `STOPPED:`이거나 승급·재시도 끝에 실패를 해결하면 카드 작성자가 기록한다. 같은 교훈이 있으면 새 줄 대신 기존 줄의 날짜만 갱신한다.
카드 쓰기 전 관련 태그로 grep하여 맞는 줄만 카드의 "배경"에 붙인다. 파일 전체를 읽지 않는다.
40줄을 넘으면 3회 이상 반복된 교훈을 기준 문서(operating-model 등)로 올리고 해당 줄을 지운다.
