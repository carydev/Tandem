description: TANDEM 하네스의 현재 상태와 실행 로그 요약을 보여준다.
---
다음을 읽고 8줄 이내로 보고해라. 파일을 고치지 마라.

1. `tandem/config.json` - 설정값
2. `{{DOCS}}/harness-status.md` - 하네스 버전, 활성 역할, 확정 모델 배치, 환경 확인 결과
3. `{{DOCS}}/log/runs.jsonl` - 총 실행 수, 성공/실패 수, 승급 건수, 모델별 사용 분포

보고 형식:
- 하네스 버전과 설치일
- 활성 역할과 모델
- 실행 통계 (총 N건 / 실패 N건 / 승급 N건)
- 눈에 띄는 신호 (승급률이 높다, 특정 조합 실패율이 높다 등). 없으면 "특이사항 없음"

로그가 비었으면 "아직 실행 기록 없음"이라고만 해라.
